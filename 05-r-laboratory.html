Part A · Sampling means

Use the supplied historical snapshot of 8,047 municipalities as a finite teaching population. Compare one sample with repeated samples of 10, 100 and 1,000 municipalities.

Municipal dataSampling scriptInference e-tivity
  1. Identify the municipal unit and the target mean.
  2. Calculate a simple random sample mean without replacement.
  3. Repeat the sampling process 200 times for each sample size.
  4. Compare empirical standard errors with the finite-population formula.
  5. Explain the different roles of sample size and repetitions.
mean(municipalities$Rp_avg)
# 14366.97: equally weighted municipal average

sum(municipalities$Rp_tot) / sum(municipalities$Rp_freq)
# 16703.62: aggregate amount / aggregate frequency

The two means answer different questions. Larger samples reduce sampling variation under the stated design. More simulation repetitions describe that variation more accurately.

Part B · Bivariate analysis

The prepared BES file has 20 non-overlapping regions. It retains Trentino-Alto Adige and excludes its two autonomous provinces. The selected education indicators match the 2020 values in the supplied source file.

BES dataBivariate scriptBivariate e-tivity
  1. Cross-tabulate geographical area and early leaving above 15%.
  2. Read row and column percentages, then check expected counts.
  3. Compare NEET percentages across two groups with Welch’s test.
  4. Compare geographical groups with ANOVA.
  5. Explore cultural participation and tertiary education with a scatterplot and correlation.
tab <- table(bes$area, bes$dropout)
prop.table(tab, margin = 1) * 100
fisher.test(tab)
t.test(neet_pct ~ dropout, data = bes)
summary(aov(neet_pct ~ area, data = bes))
cor(bes$cultural_pct, bes$tertiary_pct)
Check before interpreting a test: seven of the eight contingency-table expected counts are below 5. The script therefore demonstrates Fisher’s exact test. An exact calculation handles sparse counts under its model; it does not resolve spatial dependence or the interpretation of a complete set of regions.
Reference results
  • Cramér’s V = 0.6124; Fisher p = 0.07699.
  • Welch: mean difference = −15.075 percentage points, with 95% interval [−19.870, −10.280], using the group order “At most 15%” minus “Above 15%”.
  • Classical ANOVA: F(3,16) = 16.856, p = 0.0000330, η² = 0.7596.
  • Culture and tertiary education: Pearson r = 0.7277.

These are regional associations. Model-based tests require assumptions beyond the descriptive summaries.

Practice and interpretation

For Part A, increase the number of repetitions to 2,000 while retaining the sample sizes. For Part B, write a short report with a table or graph, the effect in meaningful units, and the conditions behind any test you use. Simple regression is an optional bridge to supervised learning.
