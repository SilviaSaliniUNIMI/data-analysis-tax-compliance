# HCAI R laboratory

Open HCAI_R_Lab.Rproj in RStudio. Run scripts/01_sampling_mean.R, then scripts/02_bivariate.R. Both scripts use base R and write graphs and CSV summaries to results/. Run line by line for teaching, or use source().

The PDF contains both parts in teaching order. Municipal income uses the supplied historical 8,047-municipality file. BES uses 20 non-overlapping regions, retaining Trentino-Alto Adige and excluding its two constituent autonomous provinces. See data_dictionary.html for definitions.

Part A: change B to 2,000 and compare with the reference results. Distinguish the number of sampling repetitions from the number of observations in one sample.
Part B: interpret one table and one graph. Check expected counts and the model assumptions before reporting a test. Multiple regression belongs to the later supervised block.
