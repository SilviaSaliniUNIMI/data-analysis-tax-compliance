# HCAI teaching materials

Author: Silvia Salini, University of Milan.

The Beamer sources cover introduction, descriptive statistics, inference, bivariate analysis and an R laboratory. Numerical foundation examples are synthetic. The R laboratory uses the supplied municipal income snapshot and BES education data.

The current R scripts retain the statistical questions of the supplied examples. The prepared BES file has 20 non-overlapping regions: Trentino-Alto Adige is retained and the two autonomous provinces are excluded. The data dictionary records variable meanings and provenance.
