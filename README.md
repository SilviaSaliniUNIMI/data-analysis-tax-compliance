# HCAI resources

Extract the package and upload its contents to the root of the GitHub Pages repository. Keep index.html directly at the root and preserve all subdirectories. Replace files with matching names.

The home page has three sections: E-tivities, Slides, Data and R scripts. Resources follow the teaching sequence.

The R laboratory combines sampling means and bivariate analysis. Its complete project is downloads/HCAI_R_Lab.zip, and its PDF is downloads/HCAI_R_Lab_2026.pdf. Open 05-r-laboratory.html for the guide. The scripts use base R and have been executed with the supplied data.

Overleaf sources are in overleaf/. Choose main.tex, descriptive_review.tex, inference.tex, bivariate.tex or r_laboratory.tex as the main document. Compile using pdfLaTeX.

Supervised and unsupervised learning materials will be added later.
